# ಕನ್ನಡ ಕಲಿ | KannadaKali 🪶

**Learn Kannada through stories, games, conversation and joyful practice.**

KannadaKali is a small learning project created to help children build confidence in Kannada through interactive and personalized activities.

## 🌱 What we are building

The project will gradually include:

- 🎮 Interactive Kannada games
- 📖 Reading activities
- 💬 Conversational Kannada practice
- 🔎 Reading Detective activities
- 🪶 Stories and adventures
- ✍️ Writing practice

## 🎯 Our Learning Approach

Every child learns differently.

KannadaKali focuses on identifying what a learner already knows, understanding where they need support, and creating activities that help them progress at their own pace.

Learning should feel like discovery — not just practice.

## 🚧 Current Development

We are starting with simple browser-based games using:

- HTML
- CSS
- JavaScript

### First Game

**Missing Word – Drag & Drop**

Children drag the correct Kannada word into a sentence to complete it.

More activities will be added as the project grows.
